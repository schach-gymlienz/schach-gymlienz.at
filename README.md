# schach-gymlienz.at

Homepage des Schachteams Gymnasium Lienz BG/BRG – Training, Jahresmeisterschaft, Turniere und Ergebnisse.

- **Mitarbeiten:** bitte zuerst [ANLEITUNG.md](ANLEITUNG.md) lesen.
- **Neuer Termin der Jahresmeisterschaft:** `python3 tools/import_termin.py Wertung.xlsx Kategoriepreise.xlsx TT.MM.JJJJ`, dann die JSON-Datei committen.
- **Lokal ansehen:** im Ordner `python3 -m http.server` starten und http://localhost:8000 öffnen (direktes Öffnen der HTML-Datei lädt die Ranglisten nicht).
